# Общий контекст OMS

OMS — доска разработки самого конвейера в форке `oh-my-symphony`.
Целевая ветка проекта — `our-main`. Каждая карточка работает со своей
зафиксированной версией кода и списком доступных файлов.

## Где искать

- `ours/hooks/` и `ours/bin/` — настройки досок, API-команды и проверки
  нашего форка. По возможности делай изменения в `ours/`.
- `src/symphony/` — ядро, API доски и браузерный интерфейс. При изменении
  ядра укажи, какое поведение требует этой правки.
- `ours/README.md` — мануал оператора. `docs/our/DECISIONS.md` — принятые
  решения, `docs/our/DEVELOPMENT.md` — порядок разработки и приёмки. Читай
  нужные разделы в пределах доступа карточки.

## Проверка и сдача

Подбирай проверки по изменению. Для обычного текста сверь дифф, ссылки
и факты. Для кода проверь затронутое поведение. Связанные небольшие правки
собираются в один выпуск. Когда для приёмки нужен полный прогон, его
выполняют один раз на точном составе выпуска.

В сдаче укажи, что изменилось для пользователя, какие проверки прошли
и какие ограничения остались. Документы в `docs/our/` пиши по-русски,
код и комментарии в коде — по-английски. Публикацию, слияние и установку
оператор подтверждает отдельно.
