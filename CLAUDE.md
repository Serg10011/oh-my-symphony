# Claude Code: дополнительная инструкция для задач человека

Общие правила форка, источники правды, порядок приёмки, проверки и рабочие
копии описаны в [`AGENTS.md`](AGENTS.md). Сначала прочитай его. При расхождении
действует `AGENTS.md`; решения по проекту — в `docs/our/DECISIONS.md`.
Этот файл применяется, когда для задачи явно выбран Claude Code. Он не задаёт
порядок работы ведущего чата Codex.

Агент конвейера: твои правила — `docs/agents/pipeline.md`; этот файл — для задач, запущенных человеком.

## Сессии существующей очереди

- Если сессию запустила очередь (`.run`), рабочая копия
  `/Users/helloworld10011/dev/oms-dev/<код>` и ветка `dev/<код>` от
  `origin/our-main` уже созданы. Не создавай и не переключай их заново.
  Задание читай по полному пути `tmp_workspaces/inbox/<код>.md` основной
  папки; первым коммитом сохрани его в `docs/our/tasks/TASK-<код>.md`.
- Сессия Claude Code не пишет в `tmp_workspaces/inbox/` и `outbox/` и не
  читает оттуда команды. Своё слияние она сама не запускает.
- Сессия очереди получает Remote Control с именем задачи. Уведомления
  отправляй только по явному разрешению Сергея на этот канал связи.

## Команды оператора очереди

Инструмент `ours/bin/inbox-runner` и четыре команд-файла остаются доступными,
если Сергей выбрал этот способ работы. Подробности — в `ours/README.md`.

- `<код>.run` — запуск готового задания. Файл пуст или содержит одну строку
  `model=sonnet|opus|haiku` и/или `effort=low|medium|high|xhigh|max` через пробел.
  Это параметры инструмента, а не рекомендации для ведущего чата.
- `<код>.test` — проверки завершённой задачи; окно сессии остаётся открытым.
- `<ID>.deliver` — пустой файл доставки карточки из `Human Review` в ветку
  `deliver/<ID>` и PR. Это подготовка результата, без слияния в `our-main`.
- `<код>.merge` — только после явного добра Сергея на слияние и обновление.
  Для доставки `<ID>.merge` содержит `deliver/<ID>` с тем же ID. После
  слияния очередь выполняет `post-merge`; для задачи Claude Code останавливает
  её процессы и закрывает окно, запомненное при `.run`.

Повтор неудачной попытки запуска — под новым кодом (например `S4-01b`);
прежнюю рабочую копию и ветку автоматически не удалять.
