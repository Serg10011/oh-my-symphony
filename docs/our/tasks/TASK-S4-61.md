# S4-61 — читаемый отчёт расходов API на русском

Добавь к api-session report удобный текстовый отчёт на русском для оператора:
итог по моделям, токены и кеш, известная стоимость с явным указанием
неизвестных списаний и основы оценки. Он должен читаться без разбора JSON.
Сохрани нынешний JSON-режим и офлайн-работу; тарифы и запуск моделей не меняй.

## Назначение и подготовка — 04.11.2026

Следующая практическая проба назначена после принятой S4-54 по поручению
Сергея «го дальше». Ведущий — DeepSeek Flash / high, Luna / max доступна
для подходящих законченных частей. Использовать её или выполнить работу
самому решает ведущий. High выбран для ограниченного форматирования
уже работающего отчёта; правило max для повышенной сложности сохраняется.
Архитектор работает с согласованным max. Для первоначальной проверки
переноса контекста рекомендована Astra/max; фактическая модель чата средой
не сообщается. Новые чаты и субагенты Codex не создаются.

Принятая база кода — a5d811d6125b71f00bf0d6cfdafe61e49c6fbc77 (PR №104).
Ветка codex/readable-api-spending также содержит 5eb033a с фактической
историей установки S4-54. Служебные копии не редактируются.

Ведущему передаются проверенные неизменившиеся фрагменты, которые он уже
читал в S4-54, через существующее поле context. Происхождение, контрольные
суммы и исключённые устаревшие материалы сохраняются отдельно.
Это операторская подготовка одной пробы, не автоматическая память карточек
и не обещание попадания в кеш. История старой задачи, её reasoning,
предложения патча, разрешения и расходы в новую сессию не копируются.

API-путь остаётся только для чтения фиксированного коммита. Результат
разработчика — unified diff и честное описание доступных проверок;
применение патча и запуск тестов выполняет оператор в рабочей копии.
Отдельного денежного budget нет по прежнему решению Сергея. Сохраняется
большой аварийный запас, без угадывания числа рабочих обращений.

Параметры — [S4-61-SESSION.json](data/S4-61-SESSION.json),
подготовка — [REPORT-53](../reports/REPORT-53.md).
Сергей разрешил первый платный запуск этой задачи ответом «разрешаю, запускай».
Разрешение действует до результата или новой остановки в сохранённых параметрах;
автоматического повтора нет. Фактический исход сохраняется в REPORT-53.
Приёмка результата, слияние и установка пока не выполнены.
