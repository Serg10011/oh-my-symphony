# S4-71 — гайд подключения проекта на странице обзора

08.11.2026 Сергей попросил закрепить на странице конвейера короткий гайд
по подключению нового проекта и созданию доски. Гайд находится над списком
досок в действующем «Обзоре проектов» из [S4-45](TASK-S4-45.md).

В свёрнутом блоке виден заголовок «Как подключить проект и создать доску».
При раскрытии видны четыре шага от запроса в проектном чате до ссылки на
новую или существующую доску. Публичную вводную можно передать в любой чат.
Для отправки подготовленного запроса используется доступ проекта на Mac
конвейера. Подтверждение платной работы остаётся отдельным действием в
настройках доски. [Вводная](../PROJECT-SETUP.md).
