# S4-76 — проверка доступности подписного исполнителя

15.11.2026 Сергей согласовал блок ответом «Го». Карточка должна сообщать,
доступен ли выбранный подписной исполнитель, прежде чем начнётся платная
работа ведущего.

## Приёмка

1. Перед чтением ключа ведущего конвейер сверяет выбранную модель с
   каталогом рабочего Antigravity CLI и проверяет открытие пустого сеанса.
2. При отказе карточка переходит в «Нужна помощь» с понятной причиной
   и нулём платных запросов к ведущему.
3. Прошедшая карточка продолжает обычный маршрут команды. Проверка
   доступности сохраняет действующую обработку квоты.
4. Проверка рабочего входа подтверждает Flash High. Доступ к Hydrogen
   определяется тем же каталогом при появлении модели в подписке.
