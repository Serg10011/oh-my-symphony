# S4-79 — материалы общего контекста OMS

15.11.2026 Сергей согласовал подготовку короткой справки для ведущего
DeepSeek. Нужны карта репозитория, порядок проверки и сдачи. На момент
сверки разрешённые `REPORT-54.md` (154 884 байта) и `ours/README.md`
(223 653 байта) превышали предел общего блока в 128 КиБ.

Справка находится в [OMS-CONTEXT.md](../../../ours/OMS-CONTEXT.md). Порядок включения
добавлен в [мануал оператора](../../../ours/README.md#выбор-api-команды).
Ветка `codex/s479-oms-context`, подготовка в архитектурном чате с усилием
`max`.

## Предпросмотр настройки рабочей OMS

В `api-settings.json` доски меняются два поля верхнего уровня.
Текущий список путей дополняется одним файлом. Отдельный список файлов
общего контекста включает только краткую справку.

```json
{
  "paths": ["docs/our/reports/REPORT-54.md", "ours/OMS-CONTEXT.md", "ours/README.md"],
  "context_paths": ["ours/OMS-CONTEXT.md"]
}
```

Настройка показана для согласования. Публикация, настройка рабочей доски
и запуск карточек требуют своего подтверждения.
