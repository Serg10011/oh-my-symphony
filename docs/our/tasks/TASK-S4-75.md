# S4-75 — завершение карточек общим выпуском

15.11.2026 Сергей согласовал блок ответом «Согласен, го». Приёмка
общего выпуска должна завершать подтвердившиеся карточки после его
установки, сохраняя результат, расходы и историю каждой задачи.

Памятка OMS-16 из API-карточки вошла в PR №121 и уже применяется в OMS.
Карточка осталась в «Нужна помощь» после собственного прогона. На этой
очереди автозапуск после входа в macOS ждёт оператора.
[Фактическое состояние](../reports/REPORT-63.md#установка-общего-выпуска-на-oms-14112026).

## Приёмка

1. Точная версия общего PR и состав карточек подтверждаются одним решением
   о выпуске.
2. После штатной установки конвейер закрывает только карточки с
   подтверждёнными результатами в этом выпуске.
3. История карточки сохраняет исходную сдачу, расходы и результаты её
   прежних проверок. В карточке доступна ссылка на общий PR.
4. На копии OMS-16 проверены завершение и готовность очереди к автозапуску.

Разработка ведётся в текущем архитектурном чате с согласованным усилием
max. Для сверки границ приёмки рекомендована Astra Max.
