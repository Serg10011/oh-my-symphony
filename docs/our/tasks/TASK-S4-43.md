## Результат и границы

Команда `ours/bin/workspace-report` читает корень рабочих мест и метаданные
досок. Показывает принадлежность папок, вид Git-копии, ветку и коммит,
состояние файлов, наличие игнорируемых данных и состояние найденной карточки.
Пути можно задать явно; по умолчанию используются `~/symphony_workspaces`
и `~/symphony-projects`. Вывод для человека — по-русски; доступен JSON.

Никаких удалений, исправления Git, fetch, prune, создания карточек, обращения
к моделям, записи в базы, правки конфигурации или управления службами.
Сама `.clean` и решение о допустимости удаления в этот блок не входят.
Сохраняется действующая политика Anthropic. Ядро и зависимости не меняются.

## Критерии (5)

1. Различаются зарегистрированная рабочая копия Git, отдельный репозиторий,
   неизвестная папка, служебные данные и ссылка. Неизвестная принадлежность
   явно указана; ссылки за пределы корня не обходятся.
2. Для доступного Git показаны ветка/HEAD, изменения и игнорируемые данные;
   для известной доски — состояние карточки и совпадение репозитория.
   Ни Done, ни чистый Git не выдаются за разрешение на удаление.
3. Команда поддерживает русский текст и JSON; ошибки чтения и повреждённые
   данные видны, неполный обзор не выдаётся за полный. Запросы Git ограничены
   по времени и не обновляют индекс, ссылки или регистрации рабочих копий.
   Если настроены внешние Git-фильтры, status не запускается и неизвестное
   состояние файлов явно отмечается; внешние команды проекта не выполняются.
4. Новые тесты используют реальные временные репозитории и проверяют
   классификацию, ссылки, ошибки и отсутствие изменений. Ruff ours и полный
   ours/tests проходят; существующие тесты не меняются и не отключаются.
5. Сохранены задание, решения, профиль, коммиты, проверки, ограничения и PR.
   Проверка на реальных папках выполняется только чтением; результат и находки
   остаются локально. Слияние и применение требуют явного добра Сергея.
