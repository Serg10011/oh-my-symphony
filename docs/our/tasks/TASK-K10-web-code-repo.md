## Цель
Новый необязательный ключ `workspace.code_repo` — абсолютный путь к git-репозиторию кода. Пусто
(по умолчанию) = как сейчас: папка WORKFLOW.md. Ключ используется ТОЛЬКО веб-маршрутами чтения:
список веток, лог, ветки задач, compare, diff. Маршруты, которые меняют репозиторий (merge, push и
подобные), ключ НЕ используют и работают с папкой WORKFLOW.md, как раньше (при внешней папке доски
они отказывают — так и должно быть: сливает человек сам). Ничего больше в ядре не трогать.

## Требования
- Строгий разбор: строка с абсолютным путём; на старте проверка, что это корень git-репозитория,
  иначе ошибка конфигурации. Пустая строка или отсутствие ключа — поведение прежнее.
- Тесты на временных репозиториях: с ключом веб-маршруты чтения показывают ветки symphony/*, лог
  и diff внешнего репозитория; без ключа — прежнее поведение; merge/push с ключом репозиторий кода
  не трогают; неверное значение ключа — ошибка конфигурации.
- Если для этого нужно больше ≈30 строк кода (без тестов) или правки вне webapi/ и разбора
  конфигурации — остановись и опиши.
