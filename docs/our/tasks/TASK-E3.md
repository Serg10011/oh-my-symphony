## 4. `project.toml` доски

- **`[checks]`**:
  - `test_globs` — шаблоны файлов тестов EVE **по самому репозиторию**: сверить с конфигом Vitest (`include`, `setupFiles`, `workspace`) и раскладкой (`tests/**`, в том числе `tests/helpers/`); стартовая точка — `["tests/**", "**/*.test.ts", "**/*.test.tsx", "**/*.spec.*"]`;

Существующие тесты защищает `test_globs` (их изменение — отказ `check.py`), отдельно в `forbidden_paths` их не пиши;
  - `allow_modified_tests`, `doc_paths` — пусто (для пробы);
  - `required_sections` — по умолчанию.
- **`[baseline] paths`** (E2) — стартовый список архитектора `["tests/**", "**/*.test.ts", "**/*.test.tsx", "**/*.spec.*", "vitest.*", "vite.config.*", "package.json", "package-lock.json", ".nvmrc", "tsconfig*.json"]`, **сверенный** с конфигом Vitest (`include`, `setupFiles`): что из найденного меняет исход тестов — добавить. Должны выполняться правила E2 (все шаблоны `test_globs` есть в `paths` буквально — иначе загрузчик откажет).

Сомнение — не добавлять. Запрет `package.json` (ниже) защищает и этот список: без него агент мог бы подменить содержимое скрипта и обойти `allowed_bash`; поэтому запрет держим, пока в `allowed_bash` есть `npm run`.
