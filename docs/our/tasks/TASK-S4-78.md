# S4-78 — общий контекст DeepSeek для карточек одного проекта

15.11.2026 Сергей согласовал блок ответом «Го». Владелец доски один раз
выбирает файлы проекта, которые ведущему полезно получать на каждой карточке.
Архитектор передаёт короткое поручение, а конвейер сам добавляет выдержанную
версию общих материалов в начало запросов к DeepSeek.

## Приёмка

1. Две карточки одной доски с одинаковыми материалами получают одинаковое
   начало запроса независимо от различий задания и других правок проекта.
2. Материалы берутся из разрешённых файлов закреплённого Git-коммита.
   Другая доска получает собственные файлы. Изменённый общий материал
   отражается в новой карточке и сохраняет прежнюю версию в старой сессии.
3. Выбранные файлы видны перед подтверждением, их версия сохраняется
   в отчёте. Сохранённые сессии без списка сохраняют формат запросов.

Проверка на копиях использует заглушки моделей. Фактическую долю кеша
DeepSeek покажет статистика отдельно согласованной реальной задачи.
Рабочие настройки и запуск карточек на OMS в эту разработку не входят.

Рабочая ветка `codex/s478-project-context`. Разработка ведётся в текущем
архитектурном чате с усилием `max`.
