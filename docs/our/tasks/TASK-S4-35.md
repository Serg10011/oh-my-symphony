ядро `src/`, тесты ядра `tests/` и зависимости. Не создавать сетевую нагрузку,

добавлять `skip`/`xfail`. Не запускать Node, агента, доску, службы,
`post-merge`, `project-doctor` или команды очереди. Работать только в этой

1. Полная обёртка в целевом тесте получает управляемые ответы от временного
   подставного сетевого счётчика и не читает сокеты/netstat хоста.

3. Регрессионные проверки доказывают вызовы подставного счётчика перед

4. Проходят целевой модуль, `python -m ruff check ours` и
   `python -m pytest ours/tests -q`; полный прогон использует Python 3.12+
