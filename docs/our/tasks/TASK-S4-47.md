# S4-47 — назначение API-исполнителей и границы подключения

02.11.2026. Сергей поручил готовить DeepSeek и OpenAI API для конвейера,
затем уточнил роли: DeepSeek ведёт обычную задачу и проверяет Luna;
для сложной работы — Sol с Luna либо один Sol. Архитектор назначает состав
и усилия, Сергей подтверждает запуск. Поручение передаётся целиком,
без разжёвывания реализации и предварительной нарезки.

## Результат

Закрепить правила назначения, ответственность куратора и исполнителя,
разделение текущего архитектора Codex и API-агентов, условия бонуса
и подтверждённые возможности существующего конвейера. Этого должно
хватить для дальнейшей подготовки подключения без путаницы между
целевой схемой и уже работающей системой.

Исполнитель подготовки — текущий чат `gpt-6.1-sol / max`, без смены
профиля и дополнительных агентов. База
`abdc974da845ab0a40d694fae2bb9f9fe9799b85`, ветка
`codex/api-executor-preparation`, отдельная рабочая копия Codex.
Архитектор назначил для подготовки первого куратора
`deepseek-v4-pro / high`, исполнителя `gpt-6-luna / max`.
Это назначение профилей, запуск API-задачи ещё не подтверждён.

## Границы

Этот законченный шаг — правила и проверка осуществимости. Установка
клиента, исполняемые профили, настройка ключей, обращения к моделям,
проверка фактического списания бонуса и автоматическая передача между
ролями остаются отдельной реализацией. Код, доски, службы и настройки
Anthropic в рамках этого шага не меняются. Секреты в документы не входят.

## Критерии (5)

1. AGENTS и DEVELOPMENT отражают назначение архитектором, подтверждение
   Сергеем и цельное поручение без предварительной нарезки.
2. Зафиксированы три состава: DeepSeek + Luna, Sol + Luna и один Sol;
   различены архитектор, куратор, исполнитель и приёмка человеком.
3. По официальной документации проверены API-модели, усилия и условия
   бонуса; стоимость всей цепочки отделена от цены кешированного входа.
4. В отчёте перечислены существующие опоры и ограничения подключения;
   непроверенная совместимость и отсутствие доступа к API отмечены явно.
5. Сохранены решение, состояние, отчёт и результаты проверок документов;
   подготовка отличена от приёмки, слияния и применения к службам.
