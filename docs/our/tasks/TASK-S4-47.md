# S4-47 — инструкция архитекторам проектов и схема API-исполнителей

02.11.2026. Сергей поручил готовить DeepSeek и OpenAI API для конвейера,
затем уточнил роли: DeepSeek ведёт обычную задачу и проверяет Luna;
для сложной работы — Sol с Luna либо один Sol. Архитектор заказывающего
проекта назначает состав и усилия, Сергей подтверждает запуск.
Текущий чат отвечает за разработку и архитектуру самого конвейера и общую
инструкцию пользования сервисом. Он также ставит задачи разработки
конвейера и согласованные тестовые задачи для обкатки; в этих случаях
сам выступает архитектором задачи. Поручение передаётся целиком,
без разжёвывания реализации и предварительной нарезки.

## Результат

Подготовить [инструкцию для архитекторов проектов](../PROJECT-ARCHITECT.md):
границы ролей, передача цельного поручения, назначения, разрешения,
получение проверенного результата и обращение при проблемах сервиса.
Разделить архитектора конвейера, архитектора проекта и API-агентов,
сохранить условия бонуса и ограничения существующего конвейера. Этого должно
хватить для дальнейшей подготовки подключения без путаницы между
целевой схемой и уже работающей системой.

Исполнитель подготовки — текущий чат `gpt-6.1-sol / max`, без смены
профиля и дополнительных агентов. База
`abdc974da845ab0a40d694fae2bb9f9fe9799b85`, ветка
`codex/api-executor-preparation`, отдельная рабочая копия Codex.
Архитектор конвейера выбрал для подготовки первого сервисного профиля куратора
`deepseek-v4-pro / high`, исполнителя `gpt-6-luna / max`.
Это заготовка профилей для проб, не назначение обычной задачи другого
проекта. Конкретная тестовая задача и её запуск ещё не подтверждены.

## Границы

Этот законченный шаг — правила и проверка осуществимости. Установка
клиента, исполняемые профили, настройка ключей, обращения к моделям,
проверка фактического списания бонуса и автоматическая передача между
ролями остаются отдельной реализацией. Код, доски, службы и настройки
Anthropic в рамках этого шага не меняются. Секреты в документы не входят.

## Критерии (5)

1. Инструкция доступна из AGENTS и ours/README; в ней различены архитектор
   проекта и архитектор конвейера, включая разработку и тестовые задачи.
2. Зафиксированы три состава: DeepSeek + Luna, Sol + Luna и один Sol;
   назначает их архитектор задачи, Сергей подтверждает запуск.
3. По официальной документации проверены API-модели, усилия и условия
   бонуса; стоимость всей цепочки отделена от цены кешированного входа.
4. Передача цельного поручения без предварительной нарезки, проверка
   результата и разрешения описаны с учётом существующих ограничений;
   непроверенная совместимость и отсутствие доступа к API отмечены явно.
5. Сохранены решение, состояние, отчёт и результаты проверок документов;
   подготовка отличена от приёмки, слияния и применения к службам.
