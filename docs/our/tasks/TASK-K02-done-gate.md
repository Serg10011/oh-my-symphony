## Цель
Добавить настройку `agent.done_gate_command` — внешнюю команду-шлюз, которая запускается при
приёмке Done и может не пустить карточку в Done. Пустая команда (значение по умолчанию) =
шлюз выключен, поведение не меняется.

## Решения (уже приняты, не пересматривай)
1. Место: `_auto_merge_done_gate_or_block` (blocked_recovery.py, около строки 467), ДО раннего
   выхода при `auto_merge_on_done: false` (у нас автослияние выключено, шлюз должен работать и
   при этом). Шлюз идёт раньше слияния: слияние выполняется только если шлюз пропустил.
2. Пути приёмки, которые шлюз обязан покрыть: воркер закончил ход; reconcile (сверка) увидел
   Done; confirm_done (TUI, веб, API).
3. Отказ шлюза → карточка в статус Blocked, тем же способом, что у ворот слияния (бери их за
   образец: как они переводят в Blocked и пишут причину). Ключ `done_gate_failure_state`
   не добавлять.
4. Запуск: текущая папка = рабочая папка карточки; переменные SYMPHONY_ISSUE_ID,
   SYMPHONY_WORKSPACE, SYMPHONY_BRANCH, SYMPHONY_ISSUE_STATE и обычные хуковые переменные.
   Команда берётся ТОЛЬКО из WORKFLOW.md, никогда из карточки или её полей.
5. Закрытый режим (при сомнении не пускать). Отказ = код возврата ≠ 0, таймаут, команда не
   найдена, любое исключение при запуске. Любой неожиданный путь выполнения ведёт к отказу.
6. Запуск не блокирует цикл событий оркестратора; при таймауте убивается вся группа
   процессов (без сирот). Если в ядре есть общий запуск хуков с таймаутом и тем же окружением,
   используй его; если нет, напиши свой и объясни выбор в отчёте.
7. Таймаут: ключ и значение по умолчанию возьми из REPORT-02, раздел 5. Если там не
   определены: `agent.done_gate_timeout_ms`, по умолчанию 300000; отметь это в отчёте как
   своё решение.
8. Разбор ключей строгий (как `_validated_bool` в K01): команда — строка (из одних пробелов =
   выключено), неверный тип — ошибка конфигурации; таймаут — положительное целое.
9. Журнал службы: события по образцу hook_failed для успеха и отказа шлюза (id карточки,
   код возврата, причина: таймаут / не найдена / код / исключение). В карточку пиши причину и
   хвост вывода команды (до ~4 КБ) в том же формате, что у ворот слияния; если для вывода
   формата нет, отдельным разделом `## Done Gate Failure`. Полный вывод в карточку не писать.
