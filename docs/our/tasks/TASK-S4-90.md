# S4-90 — упростить выбор агента

21.11.2026 Сергей согласовал подготовку черновика на отдельной копии.
Меню OMS перечисляет встроенные варианты вместе с настроенной API-командой.
Сейчас `agent.allowed_kinds` участвует в проверке запуска, поэтому
сохранённые назначения нужны и после сокращения меню.

## Поручение

Покажи в меню выбора агента только профили, явно подключённые к доске, и
подпиши фактическое назначение по умолчанию. На OMS новый список должен
начинаться с настроенной API-команды. На доске без явно настроенного списка
используется обычное меню.

Старые карточки должны показывать сохранённое назначение и продолжать
работу с ним. Настройка меню относится к новым назначениям. Проверка
возможности запуска использует действующие разрешения доски.

Подтверди это проверками для новой карточки, старого назначения и доски
без специальной настройки.
