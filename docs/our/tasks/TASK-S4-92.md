# S4-92 — Orchestrator (Neon) для карточки OMS

25.11.2026 Сергей принял NEON-4 и согласовал добавление выбора
Orchestrator (Neon) для отдельных карточек рабочей OMS. Назначение
подтверждается в карточке. Работа по подписке Antigravity с выключенными
дополнительными кредитами. Orchestrator ведёт всю задачу.

## Проба

NEON-4 выполнила одну подписочную попытку на `c4652819b` за 7 минут
21 секунду. По журналу три ответа Neon High и шесть ответов Hydrogen
High. Кнопка копирования расходов прошла проверку в Chromium. В новом
тесте исправлены два отсутствующих метода заглушки DOM. Проверенная
копия прошла восемь целевых тестов, три сценария Chromium и Ruff.
Карточка закрыта после приёмки Сергеем. Расход API $0. Остаток
пятичасовой квоты Gemini изменился с 98,57% до 96,02%, недельной
с 98,89% до 98,65%. Сохранены исходная сдача, проверенная копия и замеры.

В ранних пробах профиль Antigravity требовал интерактивное подтверждение
для разрешённых чтений. На NEON-4 применены предварительные разрешения
для изолированной копии. Штатный маршрут Flash получает данные файлов
через контроллер Symphony.

## Подключение

Доска включает выбор полем `"neon": true` в локальном
`api-settings.json`. Orchestrator доступен в составе одной карточки.
Запуск получает тот же допуск к файлам и ветку, что действующая доска.
После ответа конвейер сверяет изменённые пути, пересобирает отдельную
версию файлов и передаёт её в штатную проверку. Новая попытка требует
подтверждения. При остановке текущий процесс завершается.

Запуск ведёт Antigravity, поэтому карточка показывает его общие токены
за попытку. Для просмотра квоты используется панель остатка Gemini.
Команды исполнителя ограничены осмотром подготовленной копии.
Проверки сдачи проходят штатно на стороне конвейера.

[В проверке на копии OMS](#проверка-копии-oms) выбор и подписочное
подтверждение сверены в Chromium.

## Проверка копии OMS

В Chromium карточка показала Orchestrator как единственного исполнителя
и предложила запуск по подписке с выключенными допкредитами.
Предустановка новой карточки осталась Sol 6.2 High соло. На локальной
заглушке установленный Antigravity прочитал разрешённый файл, записал
новый и отклонил запись в защищённый файл. Проверены одна передача задания,
остановка на чужом пути и штатная подготовка версии к проверке.
Прогоны подключения к OMS выполнили без обращения к модели по подписке.
