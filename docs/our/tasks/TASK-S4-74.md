# S4-74 — просмотр досок и запуск выбранной карточки

14.11.2026 Сергей согласовал блок ответом «Го».

Из переключателя в браузере должны открываться OMS, EVE и новые внешние
доски конвейера. Карточки выключенной доски можно посмотреть сразу.
Для работы пользователь или локальный клиент выбирает конкретную карточку.
Платные API-команды запускаются по действующим правилам подтверждения.

## Приёмка

- Переключение на выключенную доску и открытие карточки обходятся чтением.
- Явный запуск подготовленной карточки отправляет в работу только её.
  Другие карточки Todo ждут своего запуска. Подзадачи принятого плана
  идут в работу по штатному правилу.
- Установленный профиль с прежней автоматической очередью можно просмотреть.
  Запуск из сохранённой доски доступен после подготовки её ручного режима.
- Поведение проверено в браузере на копиях OMS и EVE без платных запросов.
