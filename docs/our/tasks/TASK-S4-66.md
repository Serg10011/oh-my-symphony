# S4-66 — роли ведущего и исполнителя API-команды

После OMS-11 закрепить согласованное разделение работы в инструкциях,
которые действительно получают модели. Ведущий изучает задачу, передаёт
подходящую законченную реализацию исполнителю, проверяет и объединяет
результат. Исполнитель реализует порученную часть и проверяет её.
Ведущий может сам делать сложные связующие части и небольшие исправления.
Для маленького задания допустима работа одного ведущего, без обязательного
вызова второй модели. Короткое ТЗ архитектора от этого не усложняется.

Изменение относится к новым API-сессиям с отдельной рабочей копией.
Пара, усилия, права, оплата и аварийные пределы остаются назначенными
проектом. Это общее разделение ответственности команды: режим меняет
усилие ведущего, а не владельца итоговой проверки. Особенно для режима
«Экономия» второму участнику не создают искусственную работу ради участия.
Одиночная работа DeepSeek означает отсутствие вызова настроенного
исполнителя, а не автоматическое изменение состава доски.

Старые сессии и результат OMS-11 не меняются. Текстовый маршрут S4-50,
доступ только для чтения S4-53, старые Claude/Plan/Subtasks и EVE сохраняются.
В этом поручении нет новой платной задачи, публикации кандидата OMS-11,
слияния или установки. Небольшое изменение готовится для общего выпуска.

## Приёмка

1. В отправляемых инструкциях обеих ролей явно заданы реализация исполнителем
   и итоговая проверка ведущим; полезная отдельная рецензия остаётся исключением.
2. Маленькую задачу ведущий может закончить без вызова исполнителя;
   состав и усилия при этом не меняются.
3. Новые инструкции закрепляются в сессии, старые запросы воспроизводятся
   без изменения; несовпадение версии в журнале отклоняется.
4. Изоляция, кеш, ограничения и прежние проверки остаются в силе;
   проверка выполняется без реальных моделей и ключей.
