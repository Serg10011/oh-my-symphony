# S4-91 — проверка путей для правок перед запуском

21.11.2026 Сергей согласовал раннюю проверку области правок. В
[S490-1](TASK-S4-90.md#одна-платная-попытка) Sol 6.2 High соло получил
на запись `ours/hooks/project_config.py`. Защита `ours/hooks/**` выявила
правку при сдаче после 33 запросов с расчётным расходом $1,248770.

Обычная API-карточка сверяет явный список `execution.write_paths` с
действующими правилами сдачи. При конфликте панель показывает конкретный
путь до подтверждения. Прямая передача по допуску доски также возвращает
ошибку до постановки в очередь. Доступный служебный файл можно оставить
в `paths` для чтения.

Предварительная проверка охватывает явно названные существующие файлы и
пути в целиком закрытых каталогах. Список для чтения сам по себе допуска
на изменение защищённого файла не даёт. Фактические правки в любых, в том
числе смешанных, каталогах проверяются при сдаче.

`ours/hooks/project_config.py`. Карточка сохранила статус, назначение и
сессия не появились. После исключения одного пути из списка правок
предпросмотр подготовил назначение на той же базе. Все пути для чтения
сохранились, включая защищённый файл. Сессия в обоих случаях отсутствовала.

Прошёл 151 целевой тест, 2 пропущены. Проверены предпросмотр, подтверждение
после смены настроек, передача по допуску доски, чтение служебного файла и
маршруты составных задач. Ruff и проверка диффа прошли. Исходные данные
замера находятся на SSD в `checks/s490-agent-picker/preview.json` и
`checks/s490-agent-picker/run-outcome.json`.
