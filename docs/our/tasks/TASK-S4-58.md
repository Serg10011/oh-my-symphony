## Выбранные границы

Первая версия поддерживает только сохранённую остановку api_error с
network_error, возможным списанием и отсутствующим ответом. Проверяются
история запроса, активная часть Luna и незаконченная очередь поручений
ведущего. Новый ответ получает новый номер и ссылку на неопределённый
запрос; прежняя запись и её резерв не исправляются на ноль. Продолжается
тот же файл задачи с точной резервной копией исходного состояния.

Сначала локальный resume-plan, затем отдельное явно подтверждённое
платное resume с контрольной суммой плана и признанием возможного списания
потерянного ответа. План связан с путём, содержимым состояния, кодом
восстановления и будущим запросом. Обычный run остановленной сессии
по-прежнему только возвращает сохранённый итог.

Сохраняются модели/усилия, фиксированный коммит и область чтения,
пределы участников, общий расход и заданный budget. Сбой процесса в
произвольной точке, неполный ответ, отказ, неизвестный usage полученного
ответа, HTTP-ошибки и исчерпанные пределы этой версией не возобновляются.
Отдельный общий контекст карточек одного проекта и оптимизация кеша
сюда не включены; это записанные требования дальнейшей работы.
