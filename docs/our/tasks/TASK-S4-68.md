# S4-68 — доступ к OMS из чата после перезапуска Mac

## Предложение, 08.11.2026

После входа в macOS и подключения рабочего SSD архитектор снова может
открыть состояние OMS и получить результат своей карточки. Для обычного
восстановления не нужно вручную запускать доску и вход проектных чатов
из Terminal. После согласованного обновления вход загружает новую версию
в рамках штатного применения.

В первый блок входит действующая OMS и её локальный вход на 8792.
При старте проверяется, что запуск доски безопасен для сохранённой очереди.
Если на ней осталась незавершённая работа, которую запуск может подхватить,
пользователь видит причину ожидания и решает, что делать с очередью.
Доступ чата привязан к существующему проекту и работает через машину
конвейера. Настройка переносится вместе с проектом на SSD и подключается
на другом Mac существующей привязкой.

## Что подтверждено сейчас

- Установлен `0449989`. OMS работает на 9972, OMS-11 в Done, остальные
  карточки Done или Archive. В работе и повторах 0, разрешение оплаты
  `changed`. Сохранённый результат доступен через действующий вход.
  [S4-67 на рабочей доске](../reports/REPORT-62.md#установка-и-проверка-на-рабочей-доске-08112026).
- На 127.0.0.1:8792 отвечает отдельно запущенный `project-connect serve`.
  Его метки нет в пользовательских службах macOS. OMS загружена из
  `Library/Application Support/SymphonySSD/services`, а в `LaunchAgents`
  из найденных служб Symphony есть только обзор. Текущая доступность
  после входа требует восстановления обеих частей.
- В прежней S4-46 уже проверялись установка агента обзора, локальный
  адрес и управляемый перезапуск. На SSD есть штатная регистрация
  `work/host/register_services.py` и привязка `work/host/attach_mac.py`.
  Это задел для работы на новом Mac. В S4-46 реальная перезагрузка
  отдельно не проверялась. [Прежняя проверка](../reports/REPORT-36.md).

## Приёмка блока

1. На подходящем SSD при безопасной очереди после входа восстанавливаются
   одна OMS и один локальный вход. Существующий доступ `task` и `result`
   возвращает Done и сохранённый результат OMS-11.
2. При отсутствующем SSD, конфликте процесса или возможном запуске
   незавершённой задачи есть понятное состояние ожидания. Конвейер
   сохраняет карточки и историю. Сценарии проверяются на копиях.
3. Штатное согласованное обновление загружает новую версию входа и
   сохраняет привязки проекта. Повторная регистрация не плодит процессов.
4. Блок относится к OMS и входу чатов. EVE и очередь команд вне состава.
   Разрешения на модели и платные повторы определяются прежними правилами.
   Проверка установки не требует платных запусков. Факт нового входа
   после реальной перезагрузки фиксируется отдельно, когда это удобно Сергею.
