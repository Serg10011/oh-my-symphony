# S4-83 — Node для локальных JavaScript-проверок

19.11.2026 Сергей согласовал подготовку Node на отдельной копии вместе
с OMS-22. На действовавших правах запуск Homebrew Node возвращал
`Operation not permitted`. При выполнении OMS-22 команда воспользовалась
JavaScriptCore. Проверки в штатной среде Node прошли позже на Mac.
[Результат OMS-22](TASK-OMS-22.md).

Для копии использован Node v24.22.1 из уже установленного Playwright.
Ему хватает системных библиотек и чтения системного `openssl.cnf`.
Чтение разрешено только указанному бинарнику и этому системному файлу
сверх исходных прав. Путь передаётся через `SYMPHONY_NODE` из опционального
поля `execution.node`. До первого запроса к провайдеру песочница проверяет,
что указанный файл запускается и отвечает как Node. Пути внутри копии
задачи и символьные ссылки отклоняются.
[Мануал](../../../ours/README.md#рабочая-копия-и-среда-api-команды).

На копии настроек OMS штатная API-сессия сохранила назначение и
выполнила `node --check` и целевой тест из OMS-22 через указанный Node.
Отдельная проба проверила запись внутри копии, запреты чтения соседнего
файла, записи в бинарник и вне копии и подключения к локальному тестовому
сокету. Рабочие настройки OMS до и после проверки совпали.
Прошли 177 целевых тестов и 10 подсценариев, 1 тест пропущен.
Ruff прошёл. На моделях потрачено $0.

Точная конфигурация копии и результаты записаны на SSD в
`checks/s4-83-node-20261119.1t6krpck`. Установка общего выпуска
и включение параметра на рабочей OMS требуют согласования.
