## Зачем (решение архитектора, 26.10.2026)

Правки ядра Claude Code делает с высоким усилием (`claude --effort high`), а очередь сейчас умеет передавать только модель; S4-09 пришлось запускать строкой вручную. Нужен параметр усилия в `.run`.

## Требования (дословно от архитектора, выполнить все)

1. **Формат файла `.run`:** пусто или одна строка `key=value` через пробел; ключи `model` и `effort`, оба необязательны, каждый не больше одного раза, в любом порядке. Примеры допустимого: пустой файл; `model=opus`; `effort=high`; `model=sonnet effort=high`; `effort=high model=sonnet`.
2. **Без `effort` флаг `--effort` в команду не передаётся вообще** — Claude Code берёт своё усилие по умолчанию (сегодняшнее поведение). Без `model` — `sonnet`, как сейчас.
3. **Значения только из списков:** `model ∈ {sonnet, opus, haiku}` (как сейчас, `MODELS`), `effort ∈ {low, medium, high, xhigh, max}` (новая константа `EFFORTS`; это список `claude --effort`, K14). Неизвестный ключ, неизвестное значение, повтор ключа, лишние слова, вторая строка — команда не выполняется, причина пишется в отчёт/`_skipped.log` тем же путём, что сегодня для неверного `.run`. В команду Терминала подставляются только значения из списков (как сейчас для модели: `assert model in MODELS` в `terminal_command`; сделай то же для `effort`).
4. **Отчёт `outbox/<код>.run.log`:** строка вида `Запуск: model=sonnet effort=high` (или `effort=по умолчанию`, когда не задан), до шага открытия Терминала — чтобы при приёмке было видно, на каком уровне шло задание.

## Что менять

- `ours/hooks/inbox_runner.py`: константа `EFFORTS`; `parse_content("run", …)` возвращает `{"model": …, "effort": … | None}` (разбор по словам через пробел, строгие проверки из п. 3; `MODEL_LINE_RE` можно заменить на разбор `key=value`); `terminal_command(..., model, effort)` добавляет `--effort <значение>` сразу после `--model <модель>` только при заданном усилии; `do_run` принимает `effort` и пишет строку отчёта из п. 4; место вызова `do_run` в `handle` передаёт новый параметр. Больше ничего не трогать (команды `.test`/`.merge`, самоперезапуск, `run_process`).
- `ours/bin/inbox-runner`: если он лишь импортирует модуль — без изменений.

## Тесты (новые в `ours/tests/test_inbox_runner.py`; существующие не менять — если какой-то из них проверяет точную команду Терминала без `effort`, он должен остаться верным: без усилия команда прежняя)

- `.run` целиком на подменах (как существующие тесты `.run`): файл `model=opus effort=xhigh` → в отчёте строка `Запуск: model=opus effort=xhigh`, подменённый `osascript` получил команду с `--effort xhigh`; файл `effort=high` → `--model sonnet --effort high`; пустой файл → в отчёте `effort=по умолчанию`, в команде нет `--effort`; файл `effort=turbo` → команда не выполняется, причина в `_skipped.log`, рабочая копия не создаётся.
