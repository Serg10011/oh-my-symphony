После приёмки панель показывает ожидание слияния, ожидание применения
или причину, по которой подтверждение не получено. Служба выполняет сверку
в обычном фоновом обходе доски. Она использует сохранённую приёмку,
проверенную версию, статус и идентичность PR на GitHub, а также запись
успешного post-merge. Принятый коммит должен входить в точное слияние,
а слияние — в применённую версию служебной копии и клона проекта.
Это покрывает и общий выпуск с дополнительными изменениями. Сохранённая
отметка «PR влит» учитывается как часть истории карточки S4-27.

Сведения о слиянии сохраняются до проекции на доску. При возобновлении
служба повторяет только недостающую запись. Ожидание применения видно
в карточке. Прежний Done для Claude работает через свой шлюз.

Чат архитектора с доступом к машине конвейера получает отчёт по `task`
и страницы сохранённого diff по `project-connect result`. Доступ связан
с проектом и карточкой. По согласию Сергея архитектор подтверждает точную
версию через штатное локальное действие `accept`. Согласие можно дать
из чата на другом устройстве. Смена статуса на разбор или архив использует
разрешённые переходы доски. В Done переводит конвейер по доказательствам.
[Порядок для архитектора](../PROJECT-ARCHITECT.md#приёмка-из-чата).
