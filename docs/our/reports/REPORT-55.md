## Что перенесено

- Служебный Git со всеми локальными ссылками, нынешняя рабочая ветка архитектора, вложенная рабочая копия, отдельный репозиторий OMS с 12 локальными коммитами и прежние демонстрационные проекты. Ссылки между Git-копиями восстановлены на SSD.
- Обе доски с карточками, базами SQLite, правилами исполнителей, архивами и результатами. Сохранены рабочие места, прежние задания и ответы очереди, история шести серий API-прогонов и текст пяти чатов проекта на момент снимка. Секреты API хранятся в Связке ключей пользователя.
- Для выключенной доски EVE создан отдельный клон на базе `pipeline-base`, коммит `9ab79245`. Независимую разработку приложения EVE продолжает его архитектор.
- Предыдущее хранилище крупных проверок, 67 архивов и опознанные материалы из временных папок сохранены. Большие проверки по-прежнему используют `checks`.

## Работа после переключения

OMS на порту 9972 открывает рабочий процесс с внешнего диска. Общая страница на 8788 показывает OMS и выключенную EVE. Перенос проходил при пустой очереди и нуле исполняемых и повторяемых задач. Платных обращений не было. Локальные регистрации macOS запускают код, который пишет обычные журналы на SSD. Старая очередь Claude требует путей латиницей, поэтому получает два проверенных пути через короткую ссылку на тот же диск. Контроль имён, набор команд и блокировка очереди сохранены.

Два каталога, зарегистрированные в старом проекте Codex, на внутреннем диске сохранены обычными каталогами для возврата. Для новых правок следует открыть физическую папку разработки с SSD. Исходные данные остальных переключённых каталогов сохранены под соседними скрытыми именами. Точные соответствия находятся в `archives/2026-11-05-symphony-move/cutover.json`.

## Проверка и границы

Первый архив восстановлен в пустой каталог: сверены 44 244 обычных файла, десять Git-копий и обе базы. При переключении базы повторно сохранены после остановки служб. Финальный самостоятельный снимок и результаты его отдельного восстановления хранятся в `archives/2026-11-05-symphony-move`. Две Python-среды импортируют проект со своих путей на SSD и проходят проверку зависимостей. Перепривязка рабочих конфигураций проверена также с подставным именем пользователя без запуска служб.

Физического второго Mac в проверке не было. На нём нужны совместимый Python, установленные программы, доступы и регистрация служб. Ассистент миграции переносит связки ключей, одна авторизация в iCloud не подтверждает наличие двух записей в локальной связке «Вход». Содержимое ключей в архив не выгружалось. Снимок и активные файлы находятся на одном физическом носителе.
