## Что сделано

1. **`needs_human` — невыполненная зависимость.** Добавлен в `_FAILED_BLOCKER_TERMINAL_STATES` (`core_support.py:38`). Карточка с `blocked_by` на задачу в `needs_human` теперь ждёт; `Blocked` и `Human Review` ведут себя как раньше, `Done` — выполнена. Сравнение — через `normalize_state` (нижний регистр), как у соседей. Побочный эффект [код]: `blocked_recovery.py:1156` (карточка-лечение в `needs_human` раньше считалась «решённой» и могла вернуть исходную в работу при `auto_recover_blocked: true`) — теперь нет. Новых ключей нет.
2. **Текст отказа `confirm_done`.** Если отказал шлюз Done, в TUI, `POST /api/v1/<ID>/confirm-done` и веб PATCH теперь приходит `done gate failed (<причина>); moved to Blocked; workspace preserved`. При отказе ворот слияния текст прежний. Берётся `debug.last_error` только если он начинается с `done gate failed` (константа `DONE_GATE_FAILURE_PREFIX` в `constants.py`): иначе устаревшая ошибка прошлой попытки попала бы в сообщение.
3. Тесты: `tests/test_needs_human_deps.py` (8). В `tests/test_done_gate.py:356` изменена одна строка (`match=`): тест K02 ожидал старый текст именно для отказа шлюза Done, а это и есть исправляемая ошибка.

## Q1. Когда папка карточки в Human Review исчезает до `confirm_done`

| Путь | Код |
|---|---|
| Сверка: воркер ещё работает, карточка стала терминальной, прошла льгота 60 с → снимок и удаление, **в том числе для Human Review** [код] | `retry_reconcile.py:947-1040` |
| Старт службы: Human Review **сохраняется**, кроме карточек с меткой app-release (удаляются) [код] | `retry_reconcile.py:1192`, `:1130-1175` |
| Статус вне доски (например, Human Review убран из конфига) [код] | `retry_reconcile.py:1081-1105` |
| Автоархивация через `archive_after_days` (по умолчанию 30): карточка уходит в Archive, на следующем старте папка удаляется; подтвердить такую уже нельзя [код] | `sweeps.py:381-415`, `retry_reconcile.py:1266-1281` |
| Ручное удаление, `git worktree prune`, потеря контейнера — кода оркестратора нет |  |

Когда воркер завершился сам, папка Human Review остаётся (`worker_exit.py:718-722` удаляет только Done).

**Что делает `confirm_done`:** отказывает **до** шлюза (`api_views.py:86`): `workspace is missing for MT-1; restore it before confirming`. Карточка остаётся в **Human Review**, не в Blocked; шлюз не запускался, папка не пересоздана [запуск]. Ожидание «отказ → Blocked» неверно. Через API это 409 `not_confirmable`, в TUI — «confirm failed». В путях «воркер закончил»/«сверка» отсутствие папки даёт отказ шлюза → Blocked [код].

**Пересоздания из ветки `symphony/<ID>` на этом пути нет.** Оценка: ≈15–25 строк в `api_views.py` (проверить ветку через `git show-ref`, вызвать `manager.create_or_reuse`, который запустит `after_create`) + 60–80 строк тестов. Условие: без проверки ветки скрипт `after_create` создаст новую ветку от базы, и шлюз проверит пустое дерево (ложный пропуск). Несохранённые изменения восстановить нельзя — только то, что попало в снимок (`auto_commit_on_done`).

## Q2. Остановка службы или отмена во время работы шлюза

Запущено: шлюз `sleep 20`, отмена задачи через 1,5 с [запуск]. `CancelledError` не ловится `except Exception` и уходит наверх: в карточке остаётся **Done без вердикта**, заметки `Done Gate Failure` нет, артефактов `*-done_gate.*` нет, события `done_gate_passed/failed` не пишутся; процесс шлюза продолжал работать. Служба при `stop()` ждёт фоновые задачи 5 с, затем отменяет (`core.py:512-523`, `constants.py:58`) [код]. Это относится к путям «воркер закончил» и «сверка». На пути `confirm_done` Done не писался — остаётся Human Review, нажать можно снова.

**После перезапуска шлюз для такой карточки не запускается** [запуск]: на старте для Done проверяется только слияние (`retry_reconcile.py:1196-1262`), шлюз вызывают лишь три места (`worker_exit.py:865`, `retry_reconcile.py:1019`, `api_views.py:168`). Карточка остаётся в Done, папка сохранена. Закрывается правилом «агент заканчивает в Human Review» и сверкой утреннего отчёта (Done без `done_gate_passed`). Если жёстко убить службу, группа процессов шлюза (`start_new_session`) может пережить её [код].
