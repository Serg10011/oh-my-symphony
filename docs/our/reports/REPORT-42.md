## Проверка официального протокола — 03.11.2026

По OpenAI Docs [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)
поддерживает max; для reasoning с инструментами выбран Responses API.
[Function calling](https://developers.openai.com/api/docs/guides/function-calling)
связывает вызов и ответ через call_id и требует сохранять соответствующие
reasoning-элементы в диалоге. Существующая реализация сохраняет истории
ведущего и исполнителя раздельно; имитация не заменяет реальную проверку.

[DeepSeek Responses](https://api-docs.deepseek.com/guides/responses_api/)
поддерживает function calls, но остаётся stateless: previous_response_id
не используется, история передаётся явно. Cached и reasoning токены —
части входа и выхода. Автоматический кеш не гарантирует попадание.
Реальный доступ, тарификация и соблюдение контрактов не проверены.
