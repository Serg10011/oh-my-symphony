В настройках видны команда, режим и пути для новых карточек. На смешанной
OMS общая информация теперь различает API-команду для новой карточки и
базовый профиль прежнего маршрута. Владелец может увидеть разницу режима,
усилия ведущего и списка путей, затем сохранить предложенные условия.
Проверка путей опирается на действующие ограничения и файлы базовой ветки.
Список и режим хранятся с данными доски вне Git. Платное разрешение
подтверждается отдельно. [Порядок настройки](../../../ours/README.md#настройки-работы-api-доски).

Изменение режима или путей сериализовано с передачей карточек в очередь.
Если уже есть переданная задача, редактор предложит дождаться завершения.
Отклонённая попытка смены настроек оставляет допуск очередного запроса
работающей задачи доступным. Новая версия условий привязана к разрешению
доски. Возврат прежнего списка и режима требует нового подтверждения.
Назначения и проверка сохранённых результатов используют условия своей
карточки. Для работы по новой области создаётся новый черновик.
