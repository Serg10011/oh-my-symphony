## Поведение первого варианта — история

При init без переопределений новая сессия получает большой технический
запас. Явные значения сохраняют приоритет. Число 1000 является аварийным
пределом, а не прогнозом задачи, обещанием завершения или целью расхода.
Эта роль предела явно поясняется в постоянной инструкции моделям.
Счётчик включает попытки генерации всех участников, с записью in_flight
до отправки. Локальные инструменты и предварительные запросы подсчёта
входа/метаданных учитываются отдельно и не являются новыми генерациями.

| Параметр | Прежний default | Новый default |
|---|---:|---:|
| Общие ответы всех участников | 8 | 1000 |
| Выход одного ответа, включая reasoning | 2048 | 32768 |
| Общий выход сессии | 16384 | 2097152 |
| Размер одного запроса | 256 КиБ | 1 МиБ |

Настройка max_calls теперь допускает 1–100000; общий выход —
16–100000000. Прежний потолок 64 и связанный максимум 64 × 32768
сняты. Максимум одного ответа остаётся уже поддержанными адаптером 32768.
Это расширение технической настройки, без автоматического подбора модели,
усилия, числа частей или бюджета под задачу.

Выход на ответ и суммарный выход увеличены вместе с числом обращений:
изменение одного счётчика оставляло бы тесные defaults короткой пробы.
Для reasoning-моделей OpenAI документирует возможность incomplete без
видимого ответа при слишком малом выходе и рекомендует запас хотя бы
25000 токенов при первых экспериментах. Наш выбор 32768 соответствует
уже поддерживаемому локальному максимуму; он не гарантирует, что любой
ответ Flash или Luna завершится. [Официальная документация OpenAI](https://developers.openai.com/api/docs/guides/reasoning#allocating-space-for-reasoning).

Общий транспорт ждёт данные генерации 600 секунд между чтениями из
соединения вместо 120. Это read timeout, а не общий срок всей задачи
или абсолютный предел ответа. Подключение, запись, пул, подсчёт входа
OpenAI и метаданные DeepSeek сохраняют 120 секунд. Проверены оба типа
генерации и оба предварительных запроса через подставной HTTP-транспорт.
Таймаут, неизвестный расход и прочие ошибки по-прежнему терминальны;
повторных отправок нет.

## Совместимость и границы

Нормализованные limits сохраняются в состоянии при init. Show и run
не переподставляют defaults для старых полных записей; примеры 8 и 24
проверены локально. Платные журналы S4-54 с 23 и 24 ответами и исходная
подготовка Pro читаются без записи. Шесть приватных артефактов совпали
с SHA-256 до начала проверки. Старые JSON, тарифы, профили и усилия
не переписывались. Новая платная попытка требует новой подготовки;
исторический файл S4-54-SESSION.json сохраняет 24.

Общее транспортное ожидание меняется для всех новых обращений после
обновления программы; это не сохранённый параметр limits. Старый код
с потолком 64 не сможет читать новые состояния, где max_calls больше 64;
при откате такие артефакты сохраняют вместе с совместимой версией программы.

Денежный budget не включается автоматически. При заданном budget
его общий резерв и проверка перед отправкой действуют по-прежнему.
Увеличенный выход повышает предварительный резерв одного ответа:
небольшой явно заданный бюджет может остановить сессию ещё до генерации.
Для Flash с полным входом 1048576 и новым выходом 32768 текущий каталог
резервирует $0.353895; это консервативный расчёт, не фактический счёт.

Состояние ограничено прежними 16 МиБ, ответ транспорта — 4 МиБ,
запрос — максимум 1 МиБ. Доступны прежние инструменты чтения фиксированного
коммита; автоматического сокращения контекста и возобновления остановленных
сессий нет. Снятие потолка 64 само по себе не означает готовность
к неограниченно большой задаче или подтверждённую экономию.

### Актуальное поведение

Общий локальный потолок 32768 заменён проверенными пределами моделей:

- Flash 4.1 — 393216 (384 × 1024),
  [метаданные модели](https://api-docs.deepseek.com/api/list-models/);
- Luna — 128000, [документация](https://developers.openai.com/api/docs/models/gpt-6-luna);
- Sol — 128000, [документация](https://developers.openai.com/api/docs/models/gpt-6.1-sol).

Источники проверены 04.11.2026. Прежний Pro оставлен только в справочнике
для совместимости истории; рабочий профиль Flash не меняется.
Нет подбора другой модели, усилия или платного обращения для определения
этих пределов. Неизвестная модель не получает чужой предел по умолчанию.

Новый init выбирает default выхода по ведущей модели и сохраняет
output_limits каждого участника отдельно от стабильного снимка профилей.
Show показывает эти допуски. Перед отправкой берётся минимум сохранённого
допуска участника, текущей возможности его модели и общего остатка сессии
с резервом ведущего. Поэтому Luna не наследует 393216 ведущего, явные
маленькие значения сохраняются, а последующее увеличение справочника
не расширяет уже выданное разрешение. Уменьшение предела провайдера
дополнительно ограничивает запрос. Расход и денежный резерв используют
фактический предел именно отправляемого ответа.

Старые записи без output_limits продолжают использовать свой полный
сохранённый limits; просмотр не добавляет полей в файлы и не требует ключей.
Профили, усилия, тарифы и исходные платные журналы не менялись.
Сохранены 1000 ответов по умолчанию, 2097152 общего выхода, необязательный
budget и технический резерв ведущего 16 токенов; последнее не гарантирует
содержательный итог при почти исчерпанном общем выходе.

Запрос и ответ транспорта расширены до 16 МиБ, состояние — до 128 МиБ.
Это запас для приёма, нескольких представлений ответа в журнале/истории
и передачи при продолжении; прежний запрос 1 МиБ мог остановить следующий
шаг после успешно оплаченного большого ответа. Увеличение байтов не
расширяет контекстное окно модели. Ожидание данных остаётся 600 секунд
между чтениями, preflight/подключение/запись/пул — 120; повторов нет.
Автоматического сокращения контекста, продолжения остановленных сессий,
новых инструментов записи/команд и подключения API к доскам не добавлено.
Для больших задач остаются конечные ограничения данных и провайдеров.

С заданным budget Flash на 1048576 входа и 393216 выхода резервирует
$0.786432 по прежнему каталогу. Это консервативный резерв, не оплата
заранее и не счёт; после известного ответа резерв уточняется. Сам budget
не включается. Старый код с пределом 32768 или меньшими размерами может
не читать новые состояния; при откате нужен сохранённый совместимый код.
