## Что пока не подтверждено

Перенос материалов сам по себе не гарантирует попадание в серверный кеш.

разных запросов может потребовать нескольких запросов для обнаружения.
Кеш работает без гарантии полного попадания и со временем очищается.
Поэтому первые ответы новой задачи могут быть холодными; результаты
следует проверять по фактическому usage. [Документация DeepSeek,
проверена 04.11.2026](https://api-docs.deepseek.com/guides/kv_cache/).

В текущем клиенте версия Git стоит до поля context. При смене коммита
начало запроса меняется; общий кеш разных версий проекта этим этапом
не исправлен. История старой S4-54 не воспроизводится как новая задача.

ведущего ещё не реализованы. Подготовка использует существующий механизм
